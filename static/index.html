ℹ️ About This Application

Problem Statement #14 — Syllabus and Curriculum Design Optimizer

Project Overview

The Syllabus & Curriculum Design Optimizer is an AI-powered system that assists faculty in developing and refining academic course content. It autonomously analyzes syllabi, recommends improvements, and aligns topics with learning outcomes and accreditation standards.

Powered by IBM Granite on IBM Cloud Lite, the system uses natural language processing to understand curriculum goals and suggest relevant topics, assessments, and resources.

Technology Stack

AI Model: IBM Granite (granite-13b-instruct-v2)
Platform: IBM watsonx.ai (Cloud Lite)
Backend: Python + FastAPI
SDK: ibm-watsonx-ai
File Parsing: pypdf + python-docx
Standards: ABET, NAAC, NBA

Setup Instructions

  1. Create an IBM Cloud Lite account at cloud.ibm.com
  2. Provision IBM watsonx.ai service (free tier)
  3. Copy your API key and Project ID from watsonx.ai
  4. Update .env with your credentials
  5. Run pip install -r requirements.txt
  6. Start the server: python main.py
